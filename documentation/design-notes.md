# Design reference review

The five supplied websites were retrieved and rendered at 1440px and 390px, together with the bookstore admin/user dashboards and the events/CSA about pages. URLs, HTTP status, headings, fonts, and screenshot evidence are recorded in `reference-review.json` and `reference-review/`.

| Reference | Observations applied to Stackly |
| --- | --- |
| Local Farm / CSA | Clear header hierarchy, calm section transitions, purposeful introductions, and readable text/image pairs. Stackly uses a corporate split hero and restrained navy/teal palette. |
| High-End Event Planning | Spacious editorial composition and a clear CTA hierarchy. Stackly carries the spacing discipline into the executive homepage and consultation panel. |
| Local Indie Bookstore | Compact navigation, balanced featured grids, category controls, and consistent card spacing. Stackly uses aligned program and article cards with native filters. |
| FoodTruck menu | Clear inner-page introduction and simple category filtering. Stackly adapts that content-first hierarchy for the program catalog. |
| Boutique Yarn | Soft background blocks, a disciplined content width, refined rounded photography, and measured typography. Stackly uses a professional visual system suited to workplace learning. |
| Bookstore admin dashboard | Grouped left navigation, dense readable labels, restrained KPI cards, and clear workspace separation. Stackly adds real shared records rather than copying the reference's figures. |
| Bookstore user dashboard | Simple chart framing and compact information hierarchy. Stackly uses stable-height charts, text summaries, and consistent panel spacing. |
| Events and CSA about pages | Story-led section order, team/values content, and closing consultation actions. Stackly uses six purposeful company-story sections. |

The reference overview contact sheet was visually reviewed. The designs are inspiration for proportion and hierarchy; no reference CSS, markup, assets, or testimonials are copied into the delivered site.

Stackly's two homepages intentionally differ: Home 1 introduces workforce skills through a split hero, program grid, process, delivery formats, and a fictional case study. Home 2 centers on executive learning, a panoramic hero, asymmetric solutions, signature program, trainers, sessions, and a consultation close. Shared components keep the remaining pages coherent without repeating a full homepage composition.
